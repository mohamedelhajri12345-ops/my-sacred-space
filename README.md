# My Sacred Space - تطبيق إسلامي شامل 🌙

تطبيق إسلامي برازيلي متكامل يوفر تجربة روحانية غنية للمسلمين.

[![TypeScript](https://img.shields.io/badge/TypeScript-007ACC.svg?style=flat&logo=typescript&logoColor=white)](https://www.typescriptlang.org/)
[![React](https://img.shields.io/badge/React-20232A?style=flat&logo=react&logoColor=61DAFB)](https://reactjs.org/)

## ✨ المميزات

### 📖 القرآن الكريم
- تصفح القرآن كاملاً بدون إنترنت
- البحث في الآيات والعلامات المرجعية
- متابعة الختمة
- تلاوة صوتية بأكثر من قارئ

### 🕌 مواقيت الصلاة
- حساب دقيق للمواقيت حسب الموقع
- تنبيهات الأذان
- عداد تنازلي للصلاة القادمة
- اتجاه القبلة

### 📿 الأذكار والأدعية
- أذكار الصباح والمساء
- أذكار بعد الصلاة والنوم
- المسبحة الإلكترونية
- أدعية مأثورة

### 🤖 المساعد الذكي
- إجابات على الأسئلة الدينية
- مصادر ومراجع موثوقة
- يعمل بدون إنترنت (قاعدة معرفة محلية)

### 📅 التقويم الهجري
- تحويل التاريخ
- المناسبات الإسلامية

## 🚀 التشغيل

```bash
npm install
npm run dev
npm run build
npm run preview
```

## 🎨 التصميم

- **Material Design 3** مع طابع إسلامي
- ألوان هادئة: تيشن عميق + سماوي + ذهبي
- دعم الوضع الليلي
- انتقالات سلسة مع Framer Motion
